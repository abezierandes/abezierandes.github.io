# abezierandes.github.io

Root of the GitHub Pages domain. It exists to serve
`.well-known/apple-app-site-association`, which lets invite links
(`/lakadtayo-site/i/?c=CODE`) open the Lakad Tayo iOS app directly. The site
itself lives in the `lakadtayo-site` repo. `.nojekyll` keeps the `.well-known`
folder from being skipped.
